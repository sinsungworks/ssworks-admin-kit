# .claude/commands/

| 커맨드                   | 용도                                                                             | 수정 여부   |
| ------------------------ | -------------------------------------------------------------------------------- | ----------- |
| `/check`                 | lint · typecheck · test · build 를 돌리고 실패를 요약한다                        | 읽기 전용   |
| `/port <참조 파일 경로>` | 참조 프로젝트의 파일을 이 패키지 규약(명시 import · 주입 · 정본 헤더)으로 옮긴다 | 수정        |
| `/smoke`                 | 패킹한 tarball 을 임시 소비 앱에 설치해 typecheck·build 를 검증한다              | 임시 폴더만 |

`.claude/settings.json` 은 저장소 공용 허용 목록이다. `git push` · `pnpm release` 는 막혀 있다 — 발행은 release 워크플로가 한다.
